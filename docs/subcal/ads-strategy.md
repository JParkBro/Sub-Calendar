# 광고 전략

> **작업 시점: 출시 단계 (최후순위, `module-map.md` 9장).** 개인용 단계 빌드에는 광고 · 광고 제거를 넣지 않는다.

> 결정: **통계 화면 맨 아래 인라인 배너 + 구독 저장 후 빈도 제한 전면광고 + 광고 제거 1회 구매.** 보상형 광고는 1차에 넣지 않습니다 (4장 후보). 데이즈와 달리 이 앱은 서버 비용이 없어 광고와 연결할 "비용 드는 행동"이 없으므로, 사용 흐름을 해치지 않는 자리에 적게 두고 광고 제거 구매로 수익을 보완합니다.

## 1. 기본 방향

- 구독료를 아끼려는 사람이 쓰는 앱이다. 광고가 많으면 앱의 메시지와 충돌하므로 **"짧게 열고 닫는 화면"(홈 · 캘린더 · 목록)에는 광고를 두지 않는다.**
- 알림 · 위젯으로 들어온 사용자는 확인만 하고 나간다. 앱 실행 · 오프닝 광고는 쓰지 않는다.
- 광고는 미리 불러 두고, 준비되지 않았으면 건너뛴다. 로딩을 기다리게 하지 않는다.

## 2. 배치

| 위치 | 형식 | 판단 |
|---|---|---|
| 통계 화면 스크롤 맨 아래 | 적응형 배너 (인라인) | ✅ 오래 머무는 분석 화면. 콘텐츠 끝이라 실수 클릭이 적다 |
| 구독 저장 → 이전 화면으로 돌아갈 때 | 전면광고 | ✅ 빈도 제한 조건부 (3장). 작업이 끝난 자연스러운 전환점 |
| 아낀 돈 · 가성비 화면 맨 아래 | 적응형 배너 (인라인) | ✅ 2 · 3차 화면이 생기면 통계와 같은 방식 |
| 홈 · 목록 · 캘린더 · 상세 | – | ❌ 자주 · 짧게 여는 화면 |
| 하단 탭 바로 위 고정 배너 | – | ❌ 탭을 누르다 실수 클릭이 생기기 쉬움 (AdMob 정책 위험) |
| 온보딩 · 백업 · 알림 설정 | – | ❌ |
| 앱 실행 · 종료 | – | ❌ |

## 3. 전면광고 빈도 규칙

| 규칙 | 값 (Remote Config 키) |
|---|---|
| 노출 시점 | 구독 추가 · 수정 저장 후 이전 화면으로 돌아갈 때만 |
| 하루 최대 | 1회 (`ads_interstitial_daily_cap`) |
| 최소 간격 | 직전 전면광고 후 10분 (`ads_interstitial_min_interval_min`) |
| 신규 사용자 보호 | 설치 후 3일 미노출 (`ads_new_user_grace_days`) |
| 미노출 | 온보딩 일괄 등록, 무료체험 결과 선택, 백업 불러오기, 광고 제거 구매자 |
| 차단 스위치 | `ads_enabled = false`면 배너 · 전면 모두 끔 |

- 노출 기록(설치일, 마지막 노출 시각, 오늘 노출 수)은 DataStore (`data-model-erd.md` 4장).
- AdMob 콘솔에서 건너뛸 수 없는 동영상 전면광고를 끈다.

## 4. 보상형 광고 후보 (1차 미포함)

넣는다면 "없어도 앱을 다 쓸 수 있고, 보면 꾸밈이 생기는" 것만 검토합니다. 백업 · 알림 · 통계 같은 핵심 기능을 광고로 막지 않습니다.

| 후보 | 판단 |
|---|---|
| 연말 리포트 추가 카드 디자인 | ⚠️ 3차에 검토 |
| 위젯 추가 배경 | ⚠️ 2차에 검토 |
| 백업 내보내기 · 알림 개수 | ❌ 핵심 기능 |

## 5. 광고 제거 1회 구매

| 항목 | 값 |
|---|---|
| 상품 id | `remove_ads` (비소모성, Play Console 인앱 상품) |
| 가격 | ₩3,300 (Play Console 값을 그대로 표시) |
| 효과 | 배너 · 전면광고 모두 제거. 기능 차이는 없음 |
| 위치 | 더보기 → 지원 → 광고 제거, 통계 배너 아래 작은 링크 "광고 없이 쓰기" |
| 확인 | 서버 검증 없음. 앱 시작 · 화면 진입 때 `queryPurchasesAsync`로 확인하고 결과를 `remove_ads_cached`에 저장. 확인 전에는 캐시 값을 쓴다 |
| 승인 | 결제 후 `acknowledgePurchase` (3일 안에 승인하지 않으면 Play가 환불). 보류 결제는 결제 완료 후 다음 확인 때 승인 |
| 복원 | 재설치 · 기기 변경 시 같은 Google 계정이면 자동 (조회로 복원). "구매 복원" 버튼도 둔다 |
| 위험 | 클라이언트 검증만이라 우회가 가능하지만, 서버 비용을 쓰지 않는 것을 우선한다 |

## 6. AdMob 정책 체크리스트

- 전면광고는 자연스러운 전환 지점에만, 앱 열 때 · 닫을 때 띄우지 않는다.
- 광고를 닫자마자 다른 광고를 띄우지 않는다.
- 배너는 버튼 · 탭 · 입력 요소와 붙여 두지 않는다. 콘텐츠와 구분되게 "광고" 라벨.
- 맞춤 광고 동의(UMP)를 광고를 처음 띄울 때 확인한다. 동의가 필요한 지역만 화면이 뜬다.
- Play Console 앱 콘텐츠 "광고 포함", 데이터 보안(광고 ID).
